# 妖怪資料說明

## 資料結構

一般妖怪集中於 `monsters.js`；60 種古籍異獸分置於 `shanhaijing-monsters.js` 與 `shanhaijing-expansion.js`。每筆包含唯一 ID、名稱、種族、屬性、基礎等級、星級、稀有度、五項能力、山海血脈、生態或古籍形貌、技能、取得方式與固定像素生成參數。持有數量、鎖定、常用、實體等級與取得時間屬於玩家存檔，不寫回基礎資料。

96 種妖怪均有獨立 512×512 WebP 圖像，集中於 `assets/monsters/`，並由 `monster-images.js` 依穩定 ID 映射。圖鑑、詳情、煉妖結果與未發現剪影共用同一份本機圖像；`game.js` 的程序 SVG 只保留作未來新增未知 ID 時的安全機制，目前 96 種正式資料都不會觸發回退。

## 60 種山海異獸

山海異獸橫跨《南山經》《西山經》《北山經》《東山經》《中山經》《海外北經》《海內南經》《海內西經》《大荒東經》《大荒北經》。每隻都有至少一組可到達的指定配方，合計與 36 種原創妖怪構成 96 種圖鑑資料。古籍文字、白話轉譯、推測與遊戲設定嚴格分欄，詳細來源見 `SHANHAI_SOURCES.md`。

## 稀有度

- 普通：灰白，一星。
- 精良：青綠，二星。
- 稀有：藍色，三星。
- 史詩：紫色，四星。
- 傳說：金色，五星。
- 神話：赤金，六星。

能力值由基礎等級、種族偏向與稀有度倍率產生；煉妖產物的實體等級依兩隻材料平均等級與配方修正計算，並限制在 1～50。
