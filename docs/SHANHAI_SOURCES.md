# 山海異獸資料與來源說明

## 收錄範圍

本版本完成 60 種可實際取得的代表性條目，橫跨山經、海經與大荒經；這是遊戲選錄，不聲稱收錄《山海經》全部異獸。篇章分布如下：

|---|---:|
| 南山經 | 10 |
| 西山經 | 14 |
| 北山經 | 10 |
| 東山經 | 10 |
| 中山經 | 10 |
| 海外北經 | 1 |
| 海內南經 | 1 |
| 海內西經 | 1 |
| 大荒東經 | 2 |
| 大荒北經 | 1 |

每筆資料都在遊戲內保留篇章、地區、必要古籍短句、白話轉譯、形貌、行為、徵兆、合理推測、考證備註與原文頁面連結。60 種異獸也都各有至少一組可運作配方；合成關係完全屬於遊戲設定。

## 內容標籤原則

- 【古籍記載】：可在所列篇章短句核對的名稱、形貌、行為或徵兆。
- 【白話轉譯】：依短句以本作文字重述，不當作逐字翻譯。
- 【合理推測】：象徵或視覺設計上的保守推測。
- 【遊戲設定】：種族、屬性、稀有度、能力、技能、像素造型、配方與取得方式。

遊戲配方全部是玩法設計，不是《山海經》記載的合成關係。古籍中涉及食用、佩用或古代功效觀念的文字只作文獻記錄，不構成現代醫療、飲食或安全建議。

## 版本辨識示例

- 肥遺：《西山經》有六足四翼、見則大旱者；《北山經》另有一首兩身而同名者。本作條目明確採《西山經》形貌，沒有混為同一記載。
- 九尾狐：後世文學與視覺形象極多，本作只以《南山經》狐形、九尾與聲音為古籍核心，其餘技能及造型均標示為遊戲設定。
- 英招、陸吾、帝江：經文明稱「神」。本作為收集玩法列入山海異獸資料庫，但保留神靈性質的考證說明。
