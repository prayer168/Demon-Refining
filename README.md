# 《萬靈山海煉妖錄》

一款全部使用臺灣繁體中文、可離線執行的原創復古像素風妖怪收集與煉妖合成遊戲。

## 直接遊玩

公開版：https://prayer168.github.io/Demon-Refining/

解壓縮後直接以瀏覽器開啟第一層的 `index.html`。遊戲不需要安裝、不使用 API Key、不依賴外部 CDN，也不需要後端或資料庫。

若瀏覽器對 `file://` 的本機儲存政策較嚴格，可在資料夾內啟動簡易靜態伺服器：

```powershell
py -m http.server 8000
```

再開啟 `http://localhost:8000/`。

## 遊戲方式

1. 在「煉妖房」左右法陣各選一隻妖怪。
2. 查看靈石費用、成功率、屬性傾向與配方線索。
3. 確認後投入青銅爐；兩隻材料與靈石都會消耗。
4. 正確配方首次成功時會登錄配方圖鑑。一般組合則依種族與屬性規則自然化生。
5. 前往「探索」取得新妖怪、靈石、線索與殘頁，再逐步挑戰山海配方。

同種妖怪煉妖需要持有兩個不同實體；鎖定的妖怪不能作為材料。高階山海異獸只能透過指定配方與足夠血脈取得，不會從普通隨機煉妖直接出現。

## 執行測試

安裝 Node.js 後，在遊戲資料夾執行：

```powershell
node tests\validate-data.js
```

目前應顯示「全部 68 項資料與結構驗證通過」。詳細瀏覽器驗收見 `docs/TEST_REPORT.md`。

## 部署至 GitHub Pages

1. 建立新的 GitHub repository。
2. 將本資料夾內的全部檔案放在 repository 根目錄，確保根目錄直接看得到 `index.html`。
3. 提交並推送到 `main` 分支。
4. 在 GitHub repository 開啟 **Settings → Pages**。
5. **Build and deployment** 選擇 **Deploy from a branch**。
6. Branch 選擇 `main`，資料夾選擇 `/ (root)`，按 **Save**。
7. 等待 GitHub Pages 顯示網站網址後開啟即可。

遊戲完全使用相對路徑，部署在 repository 子路徑時也能正常載入。

## 存檔說明

進度儲存在瀏覽器的 LocalStorage，不會上傳。不同瀏覽器、不同裝置或不同網站網址的存檔彼此獨立。建議定期使用上方「存檔」→「匯出 JSON」備份。
