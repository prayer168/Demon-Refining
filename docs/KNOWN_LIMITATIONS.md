# 已知限制與後續擴充

本交付已達成 60 種山海異獸、100 組配方、八卷卷軸、25 項任務與完整探索／煉妖循環。仍有以下技術與設計邊界：

1. 96 種妖怪均已使用獨立 512×512 Image 2.0 WebP；目前沒有逐格角色動畫序列，待機動態由 CSS 輕量呈現。
2. 音效為 Web Audio 即時產生的短音色，目前沒有背景音樂。部分行動瀏覽器會等到第一次點擊後才允許播放。
3. 探索採短時計與獎勵池設計，沒有戰鬥系統；遊戲核心聚焦收集、合成、配方發現與卷軸推進。
4. 存檔位於瀏覽器 LocalStorage，容量及 `file://` 政策由瀏覽器決定；若直接開檔無法保存，可使用 README 的本機伺服器方式，並以 JSON 匯出備份。
5. 不同瀏覽器與網站網址的 LocalStorage 彼此獨立，遊戲未提供雲端同步或多人連線。
6. 古籍異體字與罕字在少數作業系統字型中可能顯示為缺字方框，但不影響條目 ID、資料與遊戲流程。

資料檔均使用集中式物件與穩定唯一 ID，新增異獸、地區與配方時不需改寫核心存檔格式。
